# История перемещений + чистые углы окна — дизайн

Дата: 2026-07-02

## Цель

1. Убрать «странный» светлый ореол в углах окна — сделать скругление чистым.
2. Добавить историю перемещений: список прошлых сортировок с возможностью
   откатить любую из них прямо из интерфейса.

## Углы окна

Причина ореола: панель `#glass` имела `border-radius: 16px`, а само окно
скругляется на уровне DWM (`DWMWCP_ROUND ≈ 8px`). Панель скруглена сильнее окна,
поэтому в каждом углу между дугой панели (16px) и клипом окна (8px) просвечивал
акриловый фон — светлый «серп».

Решение: совместить радиусы — `#glass { border-radius: 8px }`. Стекло и системное
скругление сохраняются, ореол пропадает. Правило на будущее: CSS-радиус панели не
должен превышать радиус скругления окна.

## История перемещений

Опирается на уже существующие логи отмены `.sorter/undo_YYYYMMDD_HHMMSS.json`
(их пишет `mover.apply`). Ничего нового хранить не нужно — история читается из них.

- `sorter/history.py`:
  - `Operation(log_path, when, entries)` + `count` — одна прошлая сортировка;
    время берётся из имени файла лога.
  - `list_operations(downloads_path)` — все операции, свежие первыми; битые и
    чужие файлы в `.sorter` тихо пропускаются.
  - `undo_operation(op)` — откат через `mover.undo` + удаление лога из истории.
- `sorter/ui_qt.py`:
  - кнопка «🕘 История» в шапке;
  - `HistoryDialog` — таблица «Когда | Файлов»; при выборе записи вторая таблица
    «Файл | Куда переместили» показывает конкретные перемещения (пути через
    `rel_to`). Кнопка «Отменить выбранную» с подтверждением; после отката главное
    окно пересобирает план (`preview`).
