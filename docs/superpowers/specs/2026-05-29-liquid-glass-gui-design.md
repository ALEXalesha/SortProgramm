# GUI Liquid Glass (PyQt6) — дизайн

Дата: 2026-05-29

## Цель

Переделать интерфейс в стиле Apple "Liquid Glass": безрамочное окно со
скруглёнными углами, настоящий системный Acrylic-фон (DWM), полупрозрачные
стеклянные карточки. Тулкит — PyQt6 (уже установлен). Оттенок — тёмное стекло
со светлым текстом.

## Технология стекла

- PyQt6, `Qt.FramelessWindowHint` + `WA_TranslucentBackground`.
- DWM через ctypes (без сторонних либ):
  - `DWMWA_SYSTEMBACKDROP_TYPE = 38`, значение `DWMSBT_TRANSIENTWINDOW = 3` (Acrylic).
  - `DWMWA_WINDOW_CORNER_PREFERENCE = 33`, значение `2` (round).
  - `DwmExtendFrameIntoClientArea` с margins -1 — чтобы материал просвечивал.
- Поверх — карточки с rgba-фоном и каймой 1px (блик по краю) через QSS.

## Своя шапка

Заголовок + кнопки свернуть/закрыть, перетаскивание окна за шапку.

## Содержимое (функции как в Tkinter-версии)

- Путь + кнопки «Открыть», «Очистить».
- Таблица превью: Файл | Куда поедет.
- Галочки «Перемещать файлы», «3D-модели → All_3d».
- Кнопка «Применить», строка статуса.

## Архитектура (ядро не трогаем)

- `sorter/ui_qt.py` — Qt-интерфейс. `sorter/ui.py` (Tkinter) остаётся запасным.
- `sorter/win_glass.py` — изолированный `apply_acrylic(hwnd)` (только Windows),
  в try/except: при неудаче — откат на полупрозрачный фон.
- `sorter/util.py` — общий `rel_to(path, root)` (убирает дубль из main.py и ui.py).
- `main.py` запускает Qt по умолчанию, флаг `--tk` — старый Tkinter.

## Надёжность

DWM-вызовы не должны ронять приложение. Сортировка быстрая → синхронно,
курсор ожидания. Потоки — позже при необходимости.
