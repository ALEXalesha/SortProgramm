# Разовая сортировка ИИ + overrides — дизайн

Дата: 2026-05-29

## Цель

Разовая аккуратная классификация реальных загрузок мной (Claude), точнее,
чем совпадение по словам. Решения сохраняются в `overrides.json`
(`имя файла → категория`), который классификатор читает первым.

## Порядок решения категории

1. `overrides.json` — точные решения (от меня сейчас, от Claude API в будущем).
2. ключевые слова из `config.json` — для новых файлов.
3. `Others` — fallback.

Тип и расширение остаются детерминированными по `type_map`.

## Изменения в коде

- `Config` получает поле `overrides: dict[str, str]` (имя файла → категория).
- `Config.load` подхватывает `overrides.json` рядом с `config.json`, если есть.
- `classify` проверяет `overrides` до ключевых слов.

## Безопасность

Конвейер не меняется: scan → classify → plan → превью → apply (с логом отмены).
Чужие папки не трогаются. Перед apply — обязательный показ плана и подтверждение.

## Шаги

1. Поддержка overrides по TDD (override бьёт ключевое слово; нет override → keyword → Others).
2. Заполнить `overrides.json` по реальному списку файлов.
3. Превью на реальных загрузках, показать план.
4. После подтверждения — apply.
5. После сортировки и проверки — отредактировать ключевые слова в `config.json`.
6. GUI-кнопка ИИ — позже (отдельный этап, Claude API).
