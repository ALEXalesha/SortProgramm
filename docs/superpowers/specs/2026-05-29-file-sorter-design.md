# Сортировщик загрузок — дизайн

Дата: 2026-05-29

## Цель

Программа на Python + Tkinter, которая раскладывает файлы из папки загрузок
по структуре **Категория (ключевое слово) → Тип → Расширение**.
Интерфейс в стиле Mouzi: кнопка "Очистить", кнопка "Открыть загрузки",
превью плана перемещений, переключатель dry-run / применить.

## Решения

| Вопрос | Решение |
|---|---|
| Язык / UI | Python + Tkinter |
| Источник ключевых слов | имя файла + содержимое (для текстовых типов) |
| Структура | Категория → Тип → Расширение, напр. `Учёба/Documents/pdf/` |
| Категории | встроенный набор по умолчанию + переопределение в `config.json` |
| Нет совпадений | категория `Others` |
| Старые папки Documents/Images/… | переразобрать в новую структуру |
| Папки программ/игр | не трогать (всё, что не в `managed_folders`) |
| Установщики | делить по ключевому слову: Игры vs Программы |
| Запуск | dry-run по умолчанию + кнопка применить |

## Категории по умолчанию

Выведены из реальных файлов в загрузках:

- **Учёба** — класс, демоверсия/demo, задачи, решения, экзамен, эссе, доклад,
  олимпиады (ВИВО/ЗИВО/ИВО/МШП), лицей, английский/математика/информатика.
- **Игры** — roblox, steam, epic, curseforge, modrinth, faceit, launcher, bluestacks.
- **3D** — blender, shader, retopo, cura, elegoo, slicer, texture, фон.
- **Код** — sim, clone, compiler, script, app-spec.
- **Дизайн** — figma, miro, holst, заготовка.
- **Программы** — прочие установщики (.exe/.msi), не попавшие в Игры.
- **Others** — fallback.

## Архитектура (модули)

- **config.py / config.json** — настройки: категории (категория → слова),
  карта расширение→тип, `managed_folders`, `ignore`, путь к загрузкам.
- **classifier.py** — файл → `(категория, тип, расширение)`. Сердце логики.
- **scanner.py** — обход корня + управляемых папок, сбор файлов. В чужие папки не заходит.
- **planner.py** — список перемещений `(откуда → куда)` с разрешением конфликтов имён.
- **mover.py** — выполнение: создание папок, перемещение, лог отмены, чистка пустых папок.
- **ui.py** — окно Tkinter.
- **main.py** — точка входа.

## Поток данных

scanner → classifier → planner → UI (превью) → mover (по кнопке "Применить").

## Классификация одного файла

1. Имя файла — есть ли слово из списка категории.
2. Если нет и файл текстовый (`txt/md/csv`, опц. `pdf/docx`) — читаем начало содержимого.
3. Иначе → категория `Others`.

Отдельно:
- **тип** = по `type_map` (Documents/Images/Videos/Archives/Installers/Code/3D/Design, иначе `Misc`).
- **расширение** = расширение в нижнем регистре.

## UI

- Путь к загрузкам, кнопка "📂 Открыть загрузки".
- Кнопка "🧹 Очистить" — строит и показывает план.
- Список-превью: `файл → Категория/Тип/расш`.
- Переключатель "Только показать / Перемещать".
- Кнопка "Применить" (активна в режиме перемещения).
- Статус: найдено N, перемещено M, пропущено K.

## Обработка ошибок

- Файл занят / нет прав → пропустить + лог, продолжить.
- Имя уже есть в цели → `файл (1).ext`, `(2)`...
- Игнор-список (недокачки, мусор) → пропустить.
- Длинные пути Windows → префикс `\\?\`.
- Пустые старые папки → удалить.
- Лог отмены последней сортировки (json) для возврата.

## Тестирование (TDD)

`pytest` на временной папке: classifier (имя/содержимое/fallback),
planner (пути, конфликты), mover (dry-run не двигает, apply двигает,
чужие папки нетронуты), игнор-список.

## Безопасность запуска

Перед работой с реальными загрузками — прогон на песочнице
(`sandbox/` в каталоге проекта) с файлами-образцами.
