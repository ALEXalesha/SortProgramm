# Пути из окна + переносимость — дизайн

Дата: 2026-05-29

## Цель

Чтобы программа работала на другом устройстве без правки кода: путь папки
для сортировки и (опционально) путь для 3D-файлов задаются прямо в окне и
сохраняются в config.json рядом с exe.

## UI (sorter/ui_qt.py)

- Редактируемое поле «Папка для сортировки» (из config.downloads_path) + кнопка «Обзор…».
- Галочка «3D-модели → отдельная папка» + поле пути рядом (из external_3d.path).
  Поле активно только при включённой галочке.
- «Очистить»/preview читают поля в config перед сканированием.

## Сохранение

- `Config.save(path)` пишет config.json обратно (downloads_path, external_3d.enabled,
  external_3d.path и все прочие поля — категории/type_map/managed/ignore сохраняются).
- overrides хранятся отдельно в overrides.json, в config.json не пишутся.
- Сохранение при «Применить» и при закрытии окна.

## Устойчивость

- `scanner.scan` по несуществующей папке возвращает [] (не падает).
- UI при несуществующей папке показывает в статусе «Папка не найдена», план пустой.

## Архитектура

Ядро не меняется по смыслу. Добавляется `Config.save`. Меняется `ui_qt.py` и `scan`.
config.json + overrides.json едут рядом с exe — это и есть переносимые настройки.

## Тесты (TDD)

- Config.save → load round-trip (значения и категории целы).
- scan по несуществующему пути → [].
